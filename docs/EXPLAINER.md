# Kitbash Assembly Bench 讲解文档

> 一个网页 3D 装配工作台:用真实无人机机架零件做交互式装配练习,
> 带自动孔位标注、磁性装配吸附和"标准答案"虚影动画。
> 仓库:https://github.com/boweili666/kitbash-assembly-bench

---

## 1. 这是什么

Kitbash Assembly Bench 是一个纯前端(three.js)的 3D 装配界面。场景里是
**Lumenier QAV-S 2 Joshua Bardwell SE** 无人机底部机架(Frame Bottom Assembly)
的全套 24 个零件 —— 4 根 5 寸碳纤机臂、前/后碳板、铝 X-Lock、2 个楔块、
4 根滚花螺柱和 13 颗 M3 螺丝。零件种类与数量取自 aristos 项目装配任务图的 BOM。

用户可以:

- 用鼠标直接拖拽零件摆放,按住 **Ctrl** 启用**磁性装配吸附**(面贴面、销入孔)
- 点 **Answer** 播放半透明虚影的**标准答案动画**:按真实装配步骤和插入方向逐件落位
- 导出装配结果为 **GLB**(可进 Blender / 游戏引擎)或 **JSON**(可再导入)

三个关键点:**孔位是从网格几何自动检测标注的**;**吸附是真实的装配约束**
(销入孔后只能沿轴滑动);**答案动画来自装配图的原始 3D 路径数据**,不是手摆的。

## 2. 快速上手

| 目标 | 操作 |
| --- | --- |
| 载入零件 | 顶栏 **Kit**(24 件全套零件清单) |
| 看答案 | 顶栏 **Answer** → 播放/调速/点步骤节点跳转/拖进度条 |
| 选择 | 点击零件;Shift+点击多选;Esc 取消 |
| 移动 | 按住零件直接拖(水平面);Shift+拖 = 垂直升降 |
| 变换手柄 | W / E / R = 移动 / 旋转 / 缩放;Q 切换 World/Local |
| **装配吸附** | **按住 Ctrl** 拖动:孔对轴自动对中、面对面自动贴平;拖远脱开 |
| 绕孔旋转 | 零件吸在孔上时按住 Ctrl:枢轴跳到孔位(Y 沿孔轴),E 拖环即绕孔转 |
| 网格吸附 | V 或顶栏 Snap:移动 0.25 / 旋转 15° / 缩放 0.1 |
| 组合 | Ctrl+G / Ctrl+Shift+G;复制 Ctrl+D;删除 Del |
| 撤销 | Ctrl+Z / Ctrl+Shift+Z(60 步快照) |
| 保存 | 自动存 localStorage;JSON 导出可再导入;GLB 导出模型 |

典型装配流程:立起一根螺柱 → Ctrl 拖后板吸上螺柱轴 → Ctrl+E 绕孔转对齐第二个孔
→ 立第二根螺柱吸上 → 螺丝转竖直、Ctrl 吸孔、Ctrl+Shift 推入 → Ctrl+G 组合。

- **零依赖运行**:three.js 及全部零件数据打包进单个 HTML(`dist/kitbash-standalone.html`),
  `file://` 双击即用;开发版 `index.html` 需 `python3 serve.py` 起本地服务器。
- 模块间通过 `window.KB / KBSnap / KBParts / KBAnswer` 极小接口协作,无框架无构建链。

## 4. 孔位自动标注(tools/label_holes.py)

原始 GLB 没有任何孔位元数据。标注脚本从三角网格自动检测圆柱特征:

1. **候选轴向**:包围盒三轴 + PCA 主轴(去重后约 3–6 个方向)。
2. **侧壁筛选**:取法线近似垂直于候选轴的三角面(|n·d| < 0.5,放宽以容纳螺纹面)。
3. **邻接聚类**:按共享边连通分量分簇(≥12 面)。
4. **圆拟合**:簇内质心投影到垂直平面,Kasa 最小二乘拟合圆;
   过滤条件:相对残差 < 0.20、弧度覆盖 ≥ 8/12 扇区(≈240°)、径向散布 < 0.5r。
5. **孔 / 销判定**:面法线指向轴心 = 孔(hole,标 H1..Hn);背离 = 销(peg,标 P1..Pn)。
6. **回转体后备**:低模螺丝的螺纹会把邻接聚类切碎 —— 此时按"所有侧壁点同轴心"
   假设,半径分带后逐带拟合;只保留**主导方向**(按最大特征深度)防止侧视幽灵圆柱。

检测结果(⌀ 为实际毫米):后板 18 孔 ⌀3.0、X-Lock 10 孔、前板 7 孔(⌀2.6–3.0)、
机臂/楔块各 1 孔、螺柱 1 孔 + ⌀5.5 柱身、每颗螺丝 ⌀3.0 杆 + ⌀5.5 头。
坐标统一换算到编辑器单位(全局 unitScale ≈ 24.77 / 米,所有零件保持真实相对尺寸,
最大零件机臂 ≈ 3 个网格单位),写入 `manifest.json`。选中零件时孔位实时渲染
琥珀圆环 + H 标签,销轴渲染蓝色。

## 5. 装配吸附(src/snap.js)

**特征提取**:每个零件在世界坐标下携带两类吸附特征 ——
孔/销的**轴**(圆心 + 方向 + 半径,来自 manifest)和包围盒的 6 个**面**(中心 + 法线)。

**求解**(拖动中每帧,按住 Ctrl 才生效):

- **轴-轴吸附**(销入孔 / 孔对孔):两轴夹角 < 20° 且垂距 < 0.32 时,
  小角度转正 + 消除垂直偏移 → 两轴共线;**沿轴分量保留**,所以吸上之后
  拖动自然退化为"沿孔轴滑动"(插拔)。半径匹配加分:⌀3 的螺丝杆优先吸 ⌀3 的孔,
  不会吸到旁边的大孔。
- **面-面吸附**:法线相对(dot < −0.90)且缝隙 < 0.30 时贴平;面内分量自由,
  吸上之后是"贴着对方表面滑动"。
- **迟滞**:进入阈值紧、脱离阈值松(轴 0.32/0.55),且**只复验当初吸上的那一对**
  特征 —— 多孔零件(18 孔的碳板)不会被其他孔"续命"导致脱不开;
  拖过一排相邻孔时会逐孔棘轮切换。
- **旋转防跳孔**:旋转拖拽期间只维持已有约束、绝不获取新吸附,
  杜绝"转一下跳到另一个孔"的抖动。

**Ctrl 门控与铰链枢轴**:松开 Ctrl 一切自由;按住 Ctrl 且零件与其他零件孔轴同轴时,
变换枢轴瞬间跳到孔位、Y 轴对齐孔轴、gizmo 自动切 Local ——
Y 箭头 = 插拔方向,Y 环 = 绕孔旋转(铰链),松开 Ctrl 立即还原到零件原点。
同一套求解器同时服务直接拖拽和 gizmo 拖拽,行为一致。

## 6. 答案动画(src/answer.js)

数据链路:aristos 的 `step_3d_paths.json`(Frame+ESC+Motors+FC 装配图的逐步 3D 路径,
毫米 + three.js XYZ 欧拉角,按零件实例 UUID 索引,与 Frame Bottom 任务图共用 UUID)——

1. 取每个零件**最后一帧位姿** = 最终装配位;按"位姿最后一次变化的步骤"得到
   **21 个安装步骤**的顺序与名称;
2. 取每个零件安装步骤内**终点前的接近/插入路径点**(丢弃远处备料区的点)——
   楔块侧向滑入、M3×22 从上往下穿、后板从下往上扣,方向全部来自原始数据;
3. 坐标换算:`t_editor = R·(offset·S) + t_mm·k`(补偿零件几何重定位 + 统一缩放),
   整体归中落地,悬浮在场景上方 1.35 单位处以免遮挡;
4. 源数据勘误:M3×22 的 #2/#3 在任务图中 UUID 重复导致缺一颗,按对称孔位镜像补全。

播放器:半透明青色虚影(不可选中、不参与吸附、不进撤销/导出),
逐件沿轨迹落位(位置折线弧长插值 + 姿态四元数球插),控制条提供
播放/暂停、0.5–2× 调速、可点可拖的进度条和 21 个步骤节点(点击跳到该步完成态,
悬停显示步骤名与所装零件)。

## 6.5 失败检测(src/check.js + snap.js)

不做物理仿真,而是把用户装配与标准答案逐件比对,每条都能现场演示:

| 规则 | 依据 | 表现 |
| --- | --- | --- |
| 放错孔位 / 位置偏差 | 以 X-Lock 为基准把标准答案对齐到当前装配(从 X-Lock 开始装);同类零件与槽位按误差全局最近配对(相同零件互换);每个零件的旋转对称(标注脚本自动检测:楔块 z180、板 z180、螺柱多重)对应的等价姿态视为同一姿态 | "M3×22 1 is in the wrong hole / position: off by 12.4 mm" |
| 用错零件 | 槽位空着但同族别种零件占了位置(螺丝↔螺丝、前板↔后板);M3×16 盘头与杯头暂视为同一种 | "Wrong part at M3×22 1's slot: found M3×16 1" |
| 螺丝方向装反 | 比较"杆→头"有向向量与答案是否反向 | "M3×22 1 is inserted backwards — the head faces the wrong way" |
| 装配顺序 | 后板 → 机臂 → 前板 的硬依赖 | "Out of order: Front Plate placed before Arm 1" |
| 完成度评分 | 24 个槽位中位置 < 3.2 mm、姿态 < 12° 且方向正确的数量 | 面板进度条 |

标注脚本为此重算了特征的**轴向区间**:用径向带内的全部顶点统计跨度(而不是聚类面片的质心跨度),
并在算杆长时剔除落在螺丝头区间内的十字槽顶点 —— 得到的杆长 22/16/6 mm、头高 3 mm、
螺柱 20 mm、板厚 2 mm 与真实零件一致,孔位比对才有毫米级精度。

## 7. 其他实现要点

- **撤销**:快照式 —— 每次操作后序列化整个场景(JSON),60 步栈;同一份 JSON
  兼做 localStorage 自动保存与导入导出格式。
- **零件实例化**:GLB 几何烘焙(节点变换 → 顶点,再套归一变换)后跨实例共享,
  材质逐实例克隆(支持改色与一键恢复默认材质)。
- **多选枢轴**:多选时临时把选中件挂到包围盒中心的枢轴组上统一变换,
  操作结束"烘焙"回原父节点;铰链枢轴复用同一机制。
- **变换重置**:一键旋转归零、缩放归一并自动落地(保持 XZ)。
- **打包**:`build.py` 把 CSS/JS/three.js/零件 GLB(base64)全部内联为单文件;
  同时产出 artifact 版本(claude.ai 在线页面)。
- **测试**:Playwright 无头回归 —— 吸附四场景(贴平/对中/沿轴滑/脱开)、
  螺丝入孔精度(偏差 0)、铰链 120° 大步长零漂移、BOM 数量逐项核对、存档恢复等。

## 8. 已知限制与方向

- 吸附只做位置/小角度姿态修正:两轴夹角 > 20° 不吸(需先用 15° 网格吸附摆正)。
- 碰撞只沿孔轴处理(销/孔/头/柱的轴向区间),零件侧向仍可互相穿透;完整碰撞需接物理引擎。
- 长条槽孔(机臂上的腰形槽)不是圆,当前不检测。
- 可能的下一步:步骤引导模式(只亮当前步骤该装的零件)、把 Checks 结果喂给 agent 做
  自然语言讲解、完整碰撞(Rapier + 凸分解)、多人协同、移动端布局。
